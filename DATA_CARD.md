# CalcGPT data card

## Overview

CalcGPT datasets contain synthetic addition and subtraction expressions. They contain no scraped text, personal data, or user-provided content.

## Formats

The padded experiment zero-pads both operands to three digits and reverses a four-character, zero-padded answer, for example `012+034=6400`.

The plain baseline uses ordinary expressions such as `12+34=46`. Its canonical
path is now `datasets/ds-calcgpt.txt`; the former long filename was removed.

Subtraction examples reorder sampled operands so that the result is non-negative. Consequently, these datasets do not represent negative arithmetic results.

## Generation and reproducibility

The canonical padded parameters are in [`configs/padded-3digit.toml`](configs/padded-3digit.toml). The scheduled reproducibility workflow regenerates the dataset with seed 42 and requires byte-for-byte equality with the tracked file.

Deterministic generation requires both a fixed pseudo-random seed and stable ordering of deduplicated examples. If the generator, Python runtime, or ordering algorithm changes intentionally, regenerate the dataset, update the checksum table, and explain the compatibility impact in the changelog.

## Evaluation hygiene

Random sampling alone does not create a guaranteed holdout. Evaluation code must
compare semantic task groups against the complete training set: addition groups
use the sorted operand pair, while subtraction remains directional. The canonical
width-3 benchmark uses seed 42, fixed independently of training seeds. Its
versioned manifest must record the exclusion policy, excluded-training-roster
hash, evaluation-roster hash, sampling procedure, seed, and final count. Every
published run report must bind to that exact benchmark-manifest hash.

## Storage policy

Small canonical datasets and test fixtures may be committed. Ad hoc or large generated datasets belong in `datasets/generated/` and should be attached to a release or external dataset repository when they are necessary to reproduce a public result.
